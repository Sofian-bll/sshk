sshk

SSH Key Manager. Pure Bash. Zero deps. One identity per purpose, one command per action.

MIT Bash OpenSSH
sshk
~ $ sshk list
github-personal ed25519 2026-01-15 ~/.ssh/keys/github-personal
gitlab-work ed25519 2026-03-02 ~/.ssh/keys/gitlab-work
homelab ed25519 2026-04-10 ~/.ssh/keys/homelab
vps-prod rsa4096 2026-05-22 ~/.ssh/keys/vps-prod

~ $ sshk create
Key name: github-new
Key type [ed25519]:
Email: sofian@example.com
[+] Created identity: github-new (ed25519)

~ $ sshk grant github-personal
[+] Key copied to clipboard for github-personal

~ $ sshk revoke github-personal
[-] Removed from ~/.ssh/authorized_keys.d/
[!] Run 'sshk copy github-personal' on remote host to re-grant

Install

curl -fsSL https://raw.githubusercontent.com/Sofian-bll/sshk/main/install.sh | bash

Commands

create
New SSH key wizard
list
List all identities
show <name>
Public key + config
copy <name>
Key to clipboard
grant <name>
Authorize on remote
revoke <name>
Remove access
delete <name>
Delete identity
help
Full reference

Structure

~/.ssh/keys/ ← Identities (one per key)
~/.ssh/authorized_keys.d/ ← Incoming access
~/.ssh/config.d/ ← Auto-assembled config
