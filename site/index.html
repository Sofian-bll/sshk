$ tree ~/.ssh

sshk gives each identity its own directory. Keys, configs, and authorized entries are namespaced and predictable.

├── keys/ # Your identities
│   ├── github/
│   │   └── id_ed25519
│   ├── vela/
│   │   └── id_ed25519
│   └── void/
│      └── id_ed25519

│   ├── github.conf
│   └── vela.conf
└── authorized_keys.d/ # Who can connect
    └── macbook

$ sshk help

One command per action. Interactive wizards for creation and setup.

$ sshk create
Interactive wizard. Pick ed25519 or RSA, set HostName and comment. Keys and config written automatically.
$ sshk list
See all your identities and who has access. Fingerprints, types, dates — everything at a glance.
$ sshk grant <name>
Push a public key to a remote server via ssh-copy-id. Organizes authorized_keys.d/ cleanly.
$ sshk revoke <name>
Remove a machine's access remotely. One command, instant revocation.
$ sshk copy <name>
Copy a public key to clipboard. Paste into GitHub, GitLab, or any service.
$ sshk show <name>
Full details: fingerprint, path, config, HostName. Everything you need to debug a connection.

$ curl install.sh | bash
